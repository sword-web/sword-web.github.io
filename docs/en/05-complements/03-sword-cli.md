# Sword CLI

::: warning In development
The `sword-cli` command line tool is currently in development.
:::

Its goal is to provide a set of utilities to make it easier to create and manage Sword projects from the terminal, such as generating modules, controllers, and providers.

For now, the recommended way to start with Sword is to review and run the [examples](https://github.com/sword-web/sword/tree/main/examples) in the repository.
