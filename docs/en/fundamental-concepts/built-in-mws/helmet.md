# Helmet (Security Headers) in Sword

The Helmet middleware in Sword uses the Helmet layer provided by [rust-helmet](https://github.com/danielkov/rust-helmet) to add HTTP security headers to outgoing responses. These headers help protect web applications against various vulnerabilities and common attacks.

This middleware is not configurable through the `.toml` file, but can be customized through code if necessary.

## Usage Example

```rust
use sword::prelude::*;
use sword::web::helmet::*;

#[sword::main]
async fn main() {
    let helmet = Helmet::builder()
        .with_header(XContentTypeOptions::NoSniff)
        .build();

    let app = Application::builder()
        .with_module::<SomeModule>()
        .with_module::<OtherModule>()
        .with_layer(helmet)
        .build();

    app.run().await;
}
```

## Available Headers

The middlewares that `axum-helmet` provides are:

| Enum/Struct                     | Configurable Values/Methods                                                                                                                                                                                                                                                                                                                                                                                                                                                     | Description                                                  |
| ------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------ |
| `CrossOriginEmbedderPolicy`     | `unsafe_none()`, `require_corp()`, `credentialless()`                                                                                                                                                                                                                                                                                                                                                                                                                           | Prevents loading cross-origin resources without permission   |
| `CrossOriginOpenerPolicy`       | `same_origin()`, `same_origin_allow_popups()`, `unsafe_none()`                                                                                                                                                                                                                                                                                                                                                                                                                  | Restricts interaction with browsing context                  |
| `CrossOriginResourcePolicy`     | `same_origin()`, `same_site()`, `cross_origin()`                                                                                                                                                                                                                                                                                                                                                                                                                                | Controls blocking of cross-origin requests                   |
| `OriginAgentCluster`            | `new(bool)`                                                                                                                                                                                                                                                                                                                                                                                                                                                                     | Indicates preference for "origin agent cluster" (true/false) |
| `ReferrerPolicy`                | `no_referrer()`, `no_referrer_when_downgrade()`, `origin()`, `origin_when_cross_origin()`, `same_origin()`, `strict_origin()`, `strict_origin_when_cross_origin()`, `unsafe_url()`                                                                                                                                                                                                                                                                                              | Controls referrer information in requests                    |
| `StrictTransportSecurity`       | `new()`, `max_age(u32)`, `include_sub_domains()`, `preload()`                                                                                                                                                                                                                                                                                                                                                                                                                   | Forces use of HTTPS                                          |
| `XContentTypeOptions`           | `nosniff()`                                                                                                                                                                                                                                                                                                                                                                                                                                                                     | Prevents MIME-sniffing                                       |
| `XDNSPrefetchControl`           | `off()`, `on()`                                                                                                                                                                                                                                                                                                                                                                                                                                                                 | Controls DNS prefetching                                     |
| `XDownloadOptions`              | `noopen()`                                                                                                                                                                                                                                                                                                                                                                                                                                                                      | Prevents execution of downloads (IE)                         |
| `XFrameOptions`                 | `deny()`, `same_origin()`, `allow_from(&str)`                                                                                                                                                                                                                                                                                                                                                                                                                                   | Prevents clickjacking via iframes                            |
| `XPermittedCrossDomainPolicies` | `none()`, `master_only()`, `by_content_type()`, `by_ftp_filename()`, `all()`                                                                                                                                                                                                                                                                                                                                                                                                    | Controls cross-domain policy files (Flash/Acrobat)           |
| `XXSSProtection`                | `off()`, `on()`, `mode_block()`, `report(&str)`                                                                                                                                                                                                                                                                                                                                                                                                                                 | Controls browser XSS filter                                  |
| `XPoweredBy`                    | `new(&str)`                                                                                                                                                                                                                                                                                                                                                                                                                                                                     | Customizes X-Powered-By header                               |
| `ContentSecurityPolicy`         | `child_src()`, `connect_src()`, `default_src()`, `font_src()`, `frame_src()`, `img_src()`, `manifest_src()`, `media_src()`, `object_src()`, `prefetch_src()`, `script_src()`, `script_src_elem()`, `script_src_attr()`, `style_src()`, `style_src_elem()`, `style_src_attr()`, `worker_src()`, `base_uri()`, `sandbox()`, `form_action()`, `frame_ancestors()`, `report_to()`, `require_trusted_types_for()`, `trusted_types()`, `upgrade_insecure_requests()`, `report_only()` | Controls resources allowed on the page                       |
