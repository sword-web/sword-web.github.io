# Iniciando con Sword

La forma más sencilla de empezar con Sword es revisar los ejemplos disponibles en el repositorio de GitHub. Cada ejemplo está diseñado para mostrar una parte concreta del framework y ayudarte a entender cómo funciona.

Por otro lado, el CLI `sword-cli` está en desarrollo y no se recomienda su uso para iniciar proyectos en este momento.

## Ejemplos

Puedes encontrar los ejemplos en el repositorio en [GitHub](https://github.com/sword-web/sword/tree/main/examples)

### Ejemplo de aplicación Web

Es el ejemplo más directo para entender el flujo base de una API REST basada en `axum` con Sword.

[Ver en GitHub](https://github.com/sword-web/sword/tree/main/examples/web)

### Ejemplo de aplicación Socket.IO

Ejemplo centrado en la integración Socket.IO con Sword, tomando como base el crate `socketioxide`.

[Ver en GitHub](https://github.com/sword-web/sword/tree/main/examples/socketio)

### Ejemplo de aplicación gRPC

Ejemplo centrado en la integración gRPC con Sword, tomando como base el crate `tonic`.

[Ver en GitHub](https://github.com/sword-web/sword/tree/main/examples/grpc)

### Ejemplo de aplicación con manejo de eventos NATs

Ejemplo centrado en la integración con el broker de eventos NATs, tomando como base el crate `async_nats`.

[Ver en GitHub](https://github.com/sword-web/sword/tree/main/examples/events)
