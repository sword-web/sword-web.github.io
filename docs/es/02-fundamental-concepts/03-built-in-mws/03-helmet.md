# Helmet (Security Headers) en Sword

El middleware Helmet en Sword utiliza la capa Helmet proporcionada por [rust-helmet](https://github.com/danielkov/rust-helmet) para agregar encabezados de seguridad HTTP a las respuestas salientes. Estos encabezados ayudan a proteger las aplicaciones web contra diversas vulnerabilidades y ataques comunes.

Este middleware no es configurable a través del archivo `.toml`, pero se puede personalizar mediante código si es necesario.

## Ejemplo de uso

```rust
use sword::prelude::*;
use sword::web::helmet::*;

#[sword::main]
async fn main() {
    let helmet = Helmet::builder()
        .with_header(XContentTypeOptions::NoSniff)
        .build();

    let app = Application::builder()
        .with_module::<SomeModule>()
        .with_module::<OtherModule>()
        .with_layer(helmet)
        .build();

    app.run().await;
}
```
